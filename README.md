# Personal Offensive Security Website

Dynamic portfolio website built with Next.js (App Router) + TypeScript + Tailwind.

## Run

- Install: `npm install`
- Dev: `npm run dev`
- Build: `npm run build`

## Content

- Landing: `src/app/page.tsx`
- Portfolio: `src/app/portfolio`
- Techniques: `src/app/techniques`
- Tools: `src/app/tools`
- Research: `src/app/research`
- Blog (Markdown): `content/blog` and `src/app/blog`
- Resume / PDFs: `public/resume.pdf`, `public/reports/*.pdf`

## Safety / Ethics

This site is intended for showcasing authorized security work. Keep client identifiers and sensitive details redacted.
